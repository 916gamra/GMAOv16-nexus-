# 🏭 توثيق صفحة سجل الآلات (Machines Registered View)
## نظام CIOB GMAO Light UI Excel

هذا الملف يوثق بالتفصيل المعماري والتقني صفحة **Machines Registered**، المتطابقة مع ورقة العمل المرجعية `Machines_Registered` في نموذج إكسيل التوأم (**Excel Twin**).

---

## 🏛️ 1. الفلسفة والهدف الوظيفي (Functional Philosophy)
- **شجرة الأصول الصناعية (Asset Tree & Equipment Hierarchy):** بطاقة تعريفية لكل آلة أو خط إنتاج في المنشأة.
- **التوليد التلقائي لرموز الآلات (Auto-ID Engine):** توليد رمز الآلة تلقائياً استناداً إلى قالب أو عائلة الآلة (مثال: `ENC-01`, `MCH-02`, `ROB-03`).
- **الربط الجغرافي والمسؤولية الميدانية:** ربط كل آلة بمنطقة افتراضية (`id_zone_default`) وفني صيانة مرجعي مسؤول عنها (`technician`).

---

## 📊 2. التطابق مع أعمدة إكسيل (Excel Twin Mapping)

| العمود في إكسيل | اسم الحقل البرمجي | النوع | الوصف والربط |
| :---: | :--- | :---: | :--- |
| **(A)** | `id_machine_registered` | `String` | الرمز الفريد للآلة (المفتاح الأساسي، مثال: `MCH-001`, `ENS-02`). |
| **(B)** | `designation` | `String` | التسمية التفصيلية للآلة أو الخط الإنتاجي. |
| **(C)** | `id_family` | `String` | المعرف المرجعي لعائلة الآلات (مرتبط بجدول `Families`). |
| **(D)** | `id_templates` | `String` | المعرف المرجعي لنموذج أو قالب الآلة (مرتبط بجدول `Templates`). |
| **(E)** | `id_zone_default` | `String` | المنطقة الصناعية الافتراضية التي تتواجد بها الآلة (مرتبط بجدول `Zones`). |
| **(F)** | `technician` | `String` | الفني الرئيسي المشرف على الصيانة (مرتبط بجدول `Technicians`). |
| **(G)** | `status` | `String` | الحالة التشغيلية للآلة (`En Service`, `En Maintenance`, `Hors Service`). |

---

## 🔗 3. التكامل مع شاشات الصرف (Integration with Sortie Rapide)
- عند اختيار نوع تدخل علاجي (`CORRECTIVE`) أو وقائي (`PREVENTIVE`) في شاشة الصرف، يتم تحميل قائمة الآلات وتصفيتها بحسب المنطقة المحددة.
- يتيح النظام إضافة آلة جديدة مباشرة من شاشة الصرف عبر النافذة المنبثقة الموحدة `AddMachineModal` دون مغادرة التدفق الحالي.
