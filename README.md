# 🏭 CIOB GMAO Light UI Excel — Enterprise Edition v3.0

> **نظام متكامل واحترافي لإدارة الصيانة بمساعدة الكمبيوتر (GMAO / CMMS) وإدارة مخزون قطع الغيار والمعدات الصناعية.**  
> يعمل بالكامل دون الحاجة إلى إنترنت (**100% Offline-First Architecture**)، مع اعتماد نموذج **التوأم الرقمي لإكسيل (Excel Twin Engine)** ومحاكاة دقيقة وفورية لمعادلات `SUMIFS` وقواعد العمل الصناعية.

---

## 🌟 الرؤية وقوة التطبيق (Core Strengths & Highlights)

تم تطوير هذا النظام ليلبي أعلى المعايير الهندسية في المنشآت الصناعية وخطوط الإنتاج، حيث يجمع بين بساطة ومرونة جداول **Excel** وقوة وموثوقية البرمجيات المؤسسية الحديثة (**Clean Architecture & Domain-Driven Design**):

1. **توأم رقمي فائق الدقة (Excel Twin Digital Engine):**
   * مطابقة حرفية لملف العمل المرجعي الصناعي `GMAO_Light_Template_V2_Formules.xlsx`.
   * محاكاة فورية لمعادلات إكسيل المعقدة (`SUMIFS`, `INDEX/MATCH`, `IF`, `VLOOKUP`).
   * حساب آلي لحظي للرصيد الفعلي للمخزون (`Stock Actuel`) وحالة التنبيه الديناميكية (`OK` / `ALERTE` / `RUPTURE`) بمجرد قيد أي حركة دخول أو خروج في زمن استجابة لا يتعدى الميكروثانية.

2. **بيئة عمل مستقلة 100% (Offline-First & PWA):**
   * تشغيل فوري وسلس في قلب الورش والمصانع بدون اتصال بالإنترنت.
   * إمكانية التثبيت كتطبيق مكتبي أو على الأجهزة المحمولة والأجهزة اللوحية الصناعية عبر معيار **PWA** و **Service Worker**.
   * تخزين هجين متعدد الطبقات (**L1 Memory Cache**, **L2 LocalStorage**, **L3 IndexedDB**) لمعالجة مئات آلاف الحركات وسجلات القطع دون أي تباطؤ.

3. **حماية وأمان صناعي متقدم (Enterprise Zero-Knowledge Vault):**
   * نظام أمان ومصادقة مشفر بالكامل يعتمد على خوارزميات التشفير القياسية (`Web Crypto API`, `AES-256`, `BCrypt`, `PBKDF2`).
   * حماية صلاحيات الوصول متعددة الأدوار (**RBAC**): `Admin`, `Chef d'Équipe`, `Technicien`, `Opérateur`.
   * قفل تلقائي عند الخمول وحماية برمز PIN سريع للعمليات الحساسة في الورشة.

4. **بنية برمجية فائقة النظافة (Clean Architecture & Modular Hooks):**
   * فصل تام للمسؤوليات: كيانات النطاق (`Domain Entities`)، خدمات التطبيق (`Application Services`)، البنية التحتية (`Persistence & IndexedDB`)، وواجهات العرض الحديثة (`Presentation Layer`).
   * إدارة حالة مجزأة ومحسّنة تمنع إعادة التصيير غير الضرورية (`useStockSubState`, `useMachineSubState`, `useMovementSubState`, `useWarehouseSubState`, `useUserSubState`).

5. **استيراد وتصدير وتدقيق شامل (Bi-directional Excel Sync & Audit Trail):**
   * تصدير واستيراد فوري لكافة الجداول بملفات Excel و JSON مع التحقق الصارم من صحة البيانات عبر مكتبة **Zod**.
   * سجل تدقيق آمن وتاريخي لكل عملية (إضافة، تعديل، صرف، إرجاع) مع توثيق هوية المستخدم والطابع الزمني الدقيق.

## 📦 الوحدات الوظيفية والشاشات (Functional Modules)

### 1. لوحة التحكم والمؤشرات الصناعية (`DashboardView`)
* مؤشرات الأداء الرئيسية (KPIs) الفورية: إجمالي المقالات، قيمة المخزون الكلية، عدد النواقص والقطع في حالة خطر، وتعداد الآلات والتدخلات.
* رسوم بيانية تفاعلية باستخدام **Recharts** توضح توزيع الحركات الشهرية، والنسب بين التدخلات العلاجية والوقائية.
* تنبيهات بصرية فورية لأي انخفاض في الرصيد تحت حد الأمان (`Seuil de Sécurité`).

### 2. إدارة المخزون وقطع الغيار (`StockView` / `PDR`)
* جدول توأم متطابق مع إكسيل يعرض: المرجع (`Code PDR`)، التسمية، النوع، الوحدة، سعر الوحدة، المخزون الأولي، مجموع الداخل، مجموع الخارج، الرصيد الحالي، وحالة القطعة (`OK` / `ALERTE` / `RUPTURE`).
* بحث متقدم فوري، وفرز حسب كافة الأعمدة، وفلاتر حسب الحالة والنوع.
* نماذج إضافة وتعديل متوافقة مع قواعد التحقق الصارمة.

### 3. الصرف السريع والتدخلات الميدانية (`SortieRapideView`)
* تدفق حركات مرن يغطي سيناريوهات الصيانة الخمسة:
  1. **Sortie Curative (علاجي):** صرف سريع لقطع غيار لإصلاح عطل مفاجئ وربطها بالآلة المتوقفة والفني المنفذ.
  2. **Sortie Préventive (وقائي):** صرف القطع المجدولة لعمليات الصيانة الدورية.
  3. **Sortie Améliorative (تحسيني):** قطع لتحديث أو تعديل خط إنتاج.
  4. **Entrée / Réapprovisionnement (إدخال وتموين):** توريد كميات جديدة للمخزن.
  5. **Sortie Externe / Bobinage (ورش خارجية):** إدارة خاصة للقطع والآلات الخارجة للورش الخارجية (مثل لف المحركات وتجديد المضخات) مع تتبع كامل لحالتها وتاريخ إرجاعها المتوقع.

### 4. مصفوفة الصيانة الوقائية والخطط (`PreventiveView`)
* جدول الصيانة المجدولة مع حساب تردد التدخلات (يومي، أسبوعي، شهري، سنوي، أو حسب ساعات التشغيل).
* ربط المهام الوقائية بالمواد المستهلكة (الزيوت، الشحوم، الفلاتر، السيور).
* بطاقات الإرشادات التقنية المعيارية (`Fiches Guides`) لتوحيد خطوات العمل بين الفنيين.
* استيراد وتصدير خطط الصيانة المنظمة بتنسيقات JSON و Excel.

### 5. سجل الآلات والمخططات الهيكلية (`Parc Machines & Blueprints`)
* شجرة تفكيك الآلات والمعدات الصناعية حسب المناطق الجغرافية وخطوط الإنتاج (`Zones`).
* نظام النماذج والقوالب (`Templates`) لتطبيق المعايير على الآلات المتشابهة.
* مخططات الـ **Blueprints** التفصيلية التي توضح ارتباط الأعضاء الميكانيكية والكهربائية بكل آلة.

### 6. المستودع وسجل الحركات التاريخي (`EntrepotView` & `MouvementsJournal`)
* تموضع فيزيائي للقطع على الرفوف وخانات التخزين (`Emplacement / Casier`).
* سجل حركات مركزي غير قابل للتلاعب، يوثق كل إدخال وإخراج برقم الإذن (`N° Bon`)، نوع الحركة، التاريخ، اسم الفني، ورقم أمر العمل.
* توليد ومعاينة إذن الصرف أو الإدخال الرقمي (`Movement Voucher Modal`).

### 7. المرجعيات الأساسية (`Référentiel`)
* إدارة موحدة للمناطق الصناعية (`Zones`)، أنواع القطع (`Part Types`)، تسميات القطع (`Designations`)، وعائلات المكونات (`Comp Families`).

### 8. المستخدمين والصلاحيات والأمان (`Utilisateurs & Security`)
* مصادقة موثوقة بالاعتماد على أسماء المستخدمين وتشفير كلمات المرور ورموز الـ PIN.
* لوحة تحكم بالصلاحيات تسمح أو تمنع تعديل الأرصدة أو الدخول للإعدادات المتقدمة حسب الدور الوظيفي.

### 9. النسخ الاحتياطي والأداء والإعدادات (`Settings & Telemetry`)
* تصدير واستيراد قواعد البيانات بنقرة واحدة (ملفات Excel أو حزم JSON مضغوطة بتقنية `LZ-String`).
* لوحة مراقبة الأداء الميداني واستهلاك الذاكرة ومعدل سرعة الحسابات (`Telemetry Audit Panel`).

## 🚀 البدء السريع والتشغيل (Quick Start)

### المتطلبات الأساسية
* بيئة تشغيل **Node.js** (الإصدار 18 أو أحدث).
* مدير الحزم **npm** أو **yarn**.

### خطوات التثبيت والتشغيل
```bash
# 1. استنساخ المستودع أو الدخول لمجلد المشروع
cd ciob-gmao-excel

# 2. تثبيت الحزم والمكتبات المطلوبة
npm install

# 3. تشغيل خادم التطوير المحلي
npm run dev

# 4. بناء نسخة الإنتاج المحسنة
npm run build

# 5. إجراء فحص الجودة المعيارية (Linting)
npm run lint

# 6. تشغيل جناح الاختبارات (Vitest)
npm run test
```

## 🤝 مساهمة وتطوير

هذا النظام تم بناؤه وتطويره بشكل مشترك ليكون حلاً صناعياً شاملاً وخالياً من التعقيدات الخارجية، مع قابلية لا متناهية للتوسع والتخصيص بما يوافق طبيعة المصنع أو الورشة.

**الترخيص:** ملكية خاصة للصيانة الصناعية وإدارة المنشآت (CIOB GMAO Light).
